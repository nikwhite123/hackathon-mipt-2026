## RT Infra Security (Frontend)

Запуск:

```bash
npm run dev
```

Бэкенд:

- Переключение на реальный API через переменные окружения:
  - `VITE_BACKEND=true`
  - `VITE_API_URL=http://localhost:8000/api`

Ожидаемые эндпоинты:

- POST `/org/settings` — сохранить настройки организации
- GET `/forecast/next` — ближайший прогноз атаки
- GET `/analytics/heatmap` — (необязательно) точки для тепловой карты
- GET `/analytics/distribution` — (необязательно) распределение атак по объектам

Код организован по принципам SOLID/DRY: отдельный API-слой с заглушками и переключателем на бэкенд, страничные компоненты без дублирования логики и с базовой доступностью.
